# DockFacts

A zero-budget, spec-verified affiliate site about **Mac docking stations and multi-display setups**. Built as a static site, generated by a zero-dependency Node script, and designed to be hosted free on GitHub Pages.

**Status (2026-11-08):** site built and committed locally; 2 published guides, 3 drafts awaiting source re-checks, and 1 free printable checklist; **$0.00 spent**; **$0.00 earned**; not yet deployed; no affiliate program active. See `BLOCKERS.md`.

**Operator:** the step-by-step account, deploy, Search Console, and affiliate checklist is in [MANUAL_TODOS.md](MANUAL_TODOS.md).

## The niche, in five lines

1. **Narrow but deep:** Apple silicon Macs have model-specific display limits (base vs Pro/Max, Thunderbolt 4 vs 5, DSC), so buyers search exact configurations rather than "best dock".
2. **Buyer intent and real commissions:** a dock is a $150–$400 purchase; even at 2–4% affiliate rates, one sale matters at low traffic, and the cookie window is generous.
3. **Low competition on the long tail:** head terms are owned by Macworld and Wirecutter, but "dual 4K 144Hz dock for M5 Air" and "TS5 vs TS5 Plus" queries are thin and answerable from primary specs.
4. **Verifiable without hands-on testing:** Apple and vendor spec pages document every claim, so an AI research desk can be accurate and transparent instead of inventing reviews.
5. **Evergreen plus a free lead magnet:** new Macs ship yearly, the compatibility questions repeat, and a display-limits cheat sheet is a useful free asset that needs no paid account.

## Quick start

Requirements: Node.js 18+ (tested on Node 24), git. No `npm install` — there are no dependencies.

```bash
npm run build          # generate docs/
npm run serve          # preview at http://localhost:8080
npm run check:affiliate # show whether any affiliate links are live
npm run check:links    # verify every cited external URL
npm run strict         # build, treat warnings as errors
```

## Deploy to GitHub Pages (free)

1. Create a public GitHub repository, e.g. `dockfacts`.
2. From this folder:
   ```bash
   git remote add origin https://github.com/<username>/dockfacts.git
   git push -u origin main
   ```
3. Repository **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, folder: **/docs**
4. Edit `site.config.json`:
   - `baseUrl`: `https://<username>.github.io/dockfacts`
   - `repoUrl`: `https://github.com/<username>/dockfacts`
5. Rebuild and commit the regenerated output:
   ```bash
   npm run build
   git add docs site.config.json
   git commit -m "Configure production URL"
   git push
   ```
6. Wait for Pages to publish, then open `https://<username>.github.io/dockfacts/`. Submit `sitemap.xml` in Google Search Console.

The output uses relative links, so the site also works from a project subpath or a custom domain without rebuilding paths. Only `baseUrl` (canonical, sitemap, feed) needs the real domain.

**Cloudflare Pages alternative:** connect the repository, set build command `node build.js`, output directory `docs`. Same result; no paid plan needed.

## Affiliate setup

`affiliate_ids.json` is the only place affiliate IDs belong. It ships with empty IDs and `enabled: false`, so every product link is currently a plain merchant link that earns nothing.

1. Apply to a program (Amazon Associates is the first candidate) using the live site URL.
2. After approval, add the tracking ID and each product ASIN:
   ```json
   "amazon_us": { "enabled": true, "id": "yourtag-20" }
   ```
3. Run `npm run check:affiliate`. It should say "ready to earn".
4. Rebuild and commit.

Articles use `[[aff:product-slug]]` or `[[aff:product-slug|label]]`; the build turns that into a tracked link with `rel="sponsored nofollow noopener"`; untagged fallbacks get `rel="noopener"` only. If a product or program is missing, the build reports it and uses the merchant fallback.

**Never invent an ASIN or reuse another publisher's tag.** Wrong ASINs mislead readers; borrowed tags violate program terms.

## Editorial rules

- No hands-on claims, invented specs, invented prices, fake reviews, or star ratings.
- Every pick links to the vendor or platform source, with a checked date.
- Prices are linked, not mirrored, unless a dated live vendor price is available.
- Affiliate disclosure appears on every article and on `/affiliate-disclosure/`.
- AI assistance is disclosed on `/about/`, `/how-we-research/`, and every article's author box.
- Two published articles per day maximum.
- If a task needs a CAPTCHA, identity document, or payment, it goes in `BLOCKERS.md` and waits for the operator.
